# Protótipo navegável do TCC Flow

Este diretório contém o protótipo de baixa fidelidade do fluxo principal do MVP.

## Como executar

1. Baixe ou clone o repositório.
2. Abra `prototype/index.html` em um navegador moderno.
3. Navegue pelos botões do protótipo.

Não há dependências, instalação ou servidor. O arquivo utiliza apenas HTML, CSS e JavaScript.

## Fluxos disponíveis

- landing page;
- dashboard demonstrativo;
- criação de projeto;
- assistente de tema;
- seleção e edição do tema;
- construtor do pré-projeto;
- orientação contextual da IA;
- confirmação explícita de decisões.

## Cenário demonstrativo

O protótipo utiliza o projeto ScriptHub como exemplo de TCC tecnológico aplicado.

## O que validar

- clareza da proposta de valor;
- facilidade para identificar a próxima ação;
- compreensão da diferença entre sugestão da IA e decisão do estudante;
- organização da jornada acadêmica;
- quantidade de informação por tela;
- comportamento em desktop e celular.

## Limitações

- dados não são persistidos;
- não existe autenticação;
- não há integração com modelo de IA;
- apenas parte das seções do pré-projeto está simulada;
- o visual ainda é exploratório e não representa a identidade final.
